# AI Agency Resources and Sales Playbooks

Curated list of commercial frameworks, course materials, tools, and templates for running an AI staffing agency.

## Primary Video Reference
* **Title:** How to Sell AI Employees (12 Hour Full Course)
* **Author / Channel:** Mani Kanasani
* **Publish Date:** October 10, 2026
* **Metrics:** ~10,625 views, 362 likes, ~12 hours runtime across 15 chapters
* **Focus:** Commercial agency playbook covering vertical selection, offer framing, sales pipeline, closing, contracting, and client onboarding.

## Free Playbook and Community Resources
* **Video Description Resources:** Access free playbooks, contract templates, and community discussion links directly in the YouTube video description.
* **Harvey Scorecard Template:** Weighted scoring matrix for evaluating candidate verticals based on operational margin, pain, and standardization.
* **15 Failure Modes Checklist:** Diagnostic sheet detailing common LLM failure scenarios in target industry workflows.
* **30-Minute Role Audit Template:** Question set for analyzing manual job tasks, hourly costs, and system access requirements with client leads.
* **CVOS Pipeline Tracker:** Tracker for managing outbound efforts across Consistency, Volume, Optimisation, and Scaling metrics.
* **Dream 100 Prospecting Sheet:** Framework for targeting top 100 ideal high-value accounts in a chosen vertical.

## Prototyping and Proving Concepts
* **Emergent:** Rapid web app prototyping tool for designing frontend application flows without full backend builds.
* **Lovable:** AI web app builder used for converting wireframes into functional client-facing prototypes during pitch meetings.

## Complementary Technical Stack
* **LangChain and LangGraph:** Orchestration frameworks for constructing stateful multi-step agent workflows.
* **Model Context Protocol (MCP):** Open standard for connecting AI models to external tools, databases, and local file systems.
* **PayPal Sandbox:** Testing environment for processing recurring subscription payments and sandbox transactions.
* **Cloudroom:** Cloud hosting and environment isolation platform for running production agents.
